# Security policy

## Supported versions

Security fixes are provided for the latest released `1.x` version on a best-effort basis.

## Reporting a vulnerability in this scanner

Please report vulnerabilities in **Domain Security Scanner itself** privately.

Preferred method: use GitHub's **Private vulnerability reporting / Report a vulnerability** feature for this repository when it is enabled.

If private vulnerability reporting is unavailable, do **not** publish exploit details, credentials, secrets, or customer data in a public issue. Open a minimal issue asking the maintainer for a private reporting channel without including sensitive details.

Useful information includes:

- affected scanner version;
- operating system and Python version;
- a minimal reproduction that does not expose third-party secrets;
- security impact;
- suggested mitigation if known.

## Findings on scanned organizations are not project vulnerabilities

Do not use this repository's public issue tracker to disclose vulnerabilities, leaked data, credentials, or sensitive findings belonging to a scanned organization. Contact the affected organization through an appropriate authorized channel.
