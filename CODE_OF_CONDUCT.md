# Code of Conduct

This project is intended to be a constructive technical community.

## Expected behavior

- Be respectful and professional.
- Critique code and technical claims, not people.
- Prefer reproducible evidence over speculation.
- Respect authorization, privacy, and responsible-disclosure boundaries.
- Do not post customer reports, credentials, secrets, or sensitive third-party findings without permission.
- Accept that maintainers may reject features that make the default scanner more intrusive, noisy, or difficult to validate.

## Unacceptable behavior

Harassment, threats, discriminatory abuse, deliberate exposure of private information, spam, or using project spaces to publish unauthorized security findings is not acceptable.

## Enforcement

The maintainer may edit, hide, lock, or remove contributions and restrict participation when necessary to protect contributors, users, or third parties.

For sensitive conduct concerns, use a private GitHub contact/reporting mechanism rather than posting personal details publicly.
